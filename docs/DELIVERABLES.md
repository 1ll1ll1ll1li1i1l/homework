### 2.2 결과 표기

- **PASS** 통과 · **FLAKY** 전체 실행에서 1회 실패, 단독 재실행 통과 · **FIX→PASS** 테스트 코드 결함 수정 후 통과 · **SKIP** 실행 제외 · **잠정** CK 미해소로 완료 조건 제외 · **N/A** 그 환경에서 실행하지 않음
- 테스트 열 약어: `PMT` = `PropertyModelTest`, `PCT` = `PropertyControllerTest`, Jest = `lwc/<컴포넌트>/__tests__/`, spec = `tests/e2e/<파일>`
- DEV = DH-DEV 최종 전체 회귀(Playwright 49/2/5) + Apex 47/47 + Jest 76/76 · SIT = DH-SIT 회귀(52/1/3 + 성능) + 배포 시 Apex 45/45 · UAT = DH-UAT 회귀(51/0/5)
- Apex AC 의 UAT 열: UAT 에서의 Apex 실행 결과는 저장소 기록이 없어 N/A 로 적었다. PROD 프로모션은 RunLocalTests 성공(§3).

### 6.1 잘된 점

- **AC 중심 개발** — AC-nnn 을 Apex 메서드명(`acNNN_*`)·Jest·Playwright test 제목에 그대로 넣어 REQ → AC → WI → 테스트 사슬을 끝까지 추적할 수 있었다.

- **안전장치** — 대상 org 가드(`support/org.ts`)로 PROD(DH-HUB) 대상 데이터 변경 테스트를 차단, `[E2E]` 데이터는 각 실행 후 정리(잔여 0건).
- **성능 목표 여유** — SIT 측정값이 목표(1초)의 약 21~76% 수준.

### 6.3 개선

- 외부 git 병합 대신 DevOps Center Promote 만 사용하거나, 병합이 필요하면 직후 Complete Promotion 절차를 체크리스트로 고정한다.
- DX Inspector 커밋 직후 `__tests__`·서식 변경 여부를 diff 로 확인하는 단계를 WI 체크리스트에 ADD 한다.
- Scratch Org 생성 직후 통화·로캘 조정을 환경 준비(Lab 3) 단계로 앞당긴다.
- 결과 기록과 동시에 Status/체크리스트 `[X]` 를 갱신해 문서 상태 지연(B-03)을 막는다.
- Flaky 테스트는 클릭·입력 단계마다 명시적 timeout 을 둔다(AC-044 교훈).
- Change Failure Rate 등 DevOps Center 지표를 Lab 12 종료 시 함께 기록한다.
