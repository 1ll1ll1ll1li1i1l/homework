## 1. 화면 목적

조건에 맞는 매물을 **카드 그리드**로 보여 주고 결과 건수와 빈 결과 안내를 표시한다. 판매완료 포함 전체 노출, 정렬·건수 상한, 빈 결과 문구를 고객과 확인한다.

## 2. Wireframe

```
┌ property-list ─────────────────────────────────────────── 10건 ┐ ← result-count (aria-live)
│ 매물 목록                                                        │
│ ┌property-card──┐ ┌property-card──┐ ┌property-card──┐          │  데스크톱 3열
│ │ 강남 래미안…   │ │ 해운대 오션뷰  │ │ 판교 테크노…   │          │  태블릿 2열
│ │₩2,500,000,000 │ │ ₩850,000,000  │ │₩1,200,000,000 │          │  모바일 1열
│ │ (판매중)       │ │ (판매중)       │ │ (계약중)       │          │
│ └───────────────┘ └───────────────┘ └───────────────┘          │
│  …  (SD 순서 — 정렬 미정 CK-06)                                  │
└──────────────────────────────────────────────────────────────────┘

 0건일 때:
┌ property-list ──────────────────────────────────────────── 0건 ┐
│                 🔍  조건에 맞는 매물이 없습니다.                 │ ← empty-state
└──────────────────────────────────────────────────────────────────┘
```

## 3. 구현 범위 (정적 데이터)

| 항목 | 목업 구현 | 본 개발(WI-1.003)에서 교체 |
|---|---|---|
| 데이터 입력 | `@api properties` — 부모(`propertyExplorer`)가 필터링한 배열 | `@wire(getProperties, { filter })` (Apex `PropertyController`) |
| 그리드 | `lightning-layout multiple-rows`, item `size=12 medium=6 large=4` | 동일 |
| 건수 | `result-count` = `{n}건` | 동일 |
| 빈 결과 | `empty-state` = `조건에 맞는 매물이 없습니다.` | 동일 |
| 로딩 | `@api isLoading` → `loading-spinner`(목업에선 항상 false) | wire 대기 중 표시 |
| 선택 | 카드 `propertyselect` 를 부모로 재발행, `@api selectedId` 로 선택 카드 강조 | 카드가 LMS 직접 발행 |
| 오류 토스트 / refresh | 생략 | `매물 정보를 불러오지 못했습니다.` / `@api refresh()` |
